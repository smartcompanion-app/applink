# Security Policy

## Supported versions

Security fixes are released for the latest minor version, as a new Docker image. Older versions are not patched.

| Version | Supported |
| ------- | --------- |
| latest minor | Yes |
| older | No |

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them through [GitHub's private vulnerability reporting](https://github.com/smartcompanion-app/applink/security/advisories/new), or by email to <hello@smartcompanion.app>.

Include the applink version (image tag), your deployment setup and enough detail to reproduce the issue. You can expect an initial response within a week.
